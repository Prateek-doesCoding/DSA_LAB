## Overview

This repository contains a collection of Data Structures and Algorithms Lab exercises completed as part of the CSE curriculum. Each solution is implemented in C, organized by topic, and includes complexity analysis where applicable.

## Repository Structure

The repository is organized into the following topic-wise directories:

### Recursion

| No. | Problem | Time Complexity | Space Complexity |
|-----|---------|------------------|-------------------|
| 1 | Factorial using Recursion | O(n) | O(n) |
| 2 | Fibonacci Sequence | O(n) | O(n) |
| 3 | Sum of N Integers via Recursion | O(n) | O(n) |

Additional topics — including Linked List, Binary Search, Stack, Queue, and Dynamic Memory Allocation — are being added progressively as the course advances.

## Build and Run Instructions

Each file is self-contained and can be compiled independently using GCC:

```bash
gcc filename.c -o output
./output
```
